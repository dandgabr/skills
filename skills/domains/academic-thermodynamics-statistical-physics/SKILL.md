# Termodinâmica e Mecânica Estatística

Esta skill estabelece as pontes microscópicas e macroscópicas para descrever o comportamento de sistemas térmicos com muitos corpos em equilíbrio e fora do equilíbrio.

---

## 🔥 1. Potenciais Termodinâmicos e Relações de Maxwell

| Potencial | Definição | Forma Diferencial Fundamental |
| :--- | :--- | :--- |
| **Energia Interna ($U$)** | $U(S, V, N)$ | $dU = T dS - P dV + \mu dN$ |
| **Entalpia ($H$)** | $H = U + PV$ | $dH = T dS + V dP + \mu dN$ |
| **Energia Livre de Helmholtz ($F$)** | $F = U - TS$ | $dF = -S dT - P dV + \mu dN$ |
| **Energia Livre de Gibbs ($G$)** | $G = H - TS$ | $dG = -S dT + V dP + \mu dN$ |

## 📊 2. Função de Partição Canônica e Distribuições Quânticas

Para um sistema canônico com estados discretos de energia $E_i$:
$$Z = \sum_i e^{-\beta E_i} \quad \text{com } \beta = \frac{1}{k_B T}$$
Número médio de ocupação de férmions (Fermi-Dirac) e bósons (Bose-Einstein):
$$\langle n(\epsilon) \rangle = \frac{1}{e^{\beta(\epsilon - \mu)} \pm 1} \quad (+ \text{ para Fermi-Dirac, } - \text{ para Bose-Einstein})$$
